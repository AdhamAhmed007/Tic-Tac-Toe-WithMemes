# 🎮 Tic-Tac-Toe (XO Game)

A fully interactive and responsive Tic-Tac-Toe game built with **HTML, CSS, and Vanilla JavaScript**.
This project focuses on clean UI design, modular JavaScript logic, and smooth user experience.

---

## 🚀 Live Demo

https://adhamahmed007.github.io/Tic-Tac-Toe-WithMemes/

---

## ✨ Features

* 🎯 Two-player game (X vs O)
* 🧠 Smart win detection (rows, columns, diagonals)
* 🤝 Draw detection
* 🔄 Restart game functionality
* 🎨 Clean and responsive UI
* ⚡ Smooth user interaction

---

## 🛠️ Built With

* HTML5 – Structure
* CSS3 – Styling & Layout
* JavaScript (Vanilla) – Game Logic & DOM Manipulation

---

## 🧠 How It Works

The game logic is built using JavaScript and follows these steps:

* Track player turns (X / O)
* Listen for user clicks on the grid
* Update the UI dynamically
* Check all winning conditions after each move
* Display winner or draw message
* Allow game reset without page reload
